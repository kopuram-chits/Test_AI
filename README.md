# EmployeeAPI (.NET 8)

A simple ASP.NET Core Web API demonstrating CRUD operations with an in-memory `List<Employee>` and a separate service layer.

## Requirements
- .NET 8 SDK

## Run
```bash
dotnet restore
dotnet run
```

Open the Swagger URL printed in the terminal (usually `https://localhost:<port>/swagger`).

## Project structure
```text
EmployeeAPI/
├── Controllers/
│   └── EmployeeController.cs
├── Models/
│   └── Employee.cs
├── Services/
│   ├── IEmployeeService.cs
│   └── EmployeeService.cs
├── EmployeeAPI.csproj
└── Program.cs
```

## Endpoints

| Method | URL | Description |
|---|---|---|
| GET | `/api/Employee` | Get all employees |
| GET | `/api/Employee/{id}` | Get employee by ID |
| POST | `/api/Employee` | Create an employee (ID is generated) |
| PUT | `/api/Employee/{id}` | Update name, salary and DOB |
| DELETE | `/api/Employee/{id}` | Delete an employee |

### POST example
`POST /api/Employee`
```json
{
  "name": "Jay",
  "salary": 55000,
  "dob": "1990-10-15"
}
```

### PUT example
`PUT /api/Employee/1`
```json
{
  "name": "Rahul Updated",
  "salary": 65000,
  "dob": "1995-05-10"
}
```

## Notes
- `EmployeeService` is registered as a singleton, so the same in-memory collection is used across requests.
- The service uses a lock to protect list operations from concurrent requests.
- IDs are generated by the service.
- Data is not persisted. It resets when the application restarts.
